# Bring-up 与开发顺序

每阶段保留基线提交、内核/DT/镜像哈希、硬件版本、接线和日志。表中项目全部是计划，尚未通过。

| 阶段 | 内容 | 完成条件 |
|---|---|---|
| 0：资料 | 最新原理图/网表、屏幕资料、完整厂商参考包、启动/恢复流程 | 来源可追溯，管脚、电压域、Flash 分区和 DDR 型号明确 |
| 1：启动 | DDR 初始化、启动程序、6.18、串口、initramfs | 可重复启动到 shell，内存容量正确，两核上线，保留完整日志 |
| 2：基础系统 | SPI NAND/MTD/UBI、网络、USB Host/Device、I²C | 核对数据完整性、断开恢复和各接口真实功能 |
| 3：控制与电源 | PC 电源/复位、LED、STC 协议和自身关机 | 默认输出安全、重启不误触发，数据保存后完成 Controller 断电 |
| 4：副屏 | 面板供电/复位/DSI、触摸、Dashboard | 显示正确，休眠/唤醒行为明确，触摸坐标正确 |
| 5：视频 | LT8619C、T113 CSI、采集 DMA | 逐档验证格式、帧序、丢帧和 HDMI 重插/分辨率变化 |
| 6：编码与 KVM | JPEG/MJPEG 编码、视频传输、USB HID | 达到冻结后的分辨率、帧率、延迟和输入正确性要求 |
| 7：并发与恢复 | KVM + Dashboard + 遥测、温度、电源恢复 | 并发负载下无数据错误，性能/温度达标，升级失败可恢复 |
