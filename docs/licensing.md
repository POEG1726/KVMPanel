# 许可证与资料管理

- 本项目尚未决定自有代码许可证，暂不添加覆盖上游源码的笼统 LICENSE。
- Linux、U-Boot、Buildroot 和各厂商参考代码保留各自原有许可证及版权声明。
- 移植 GPL 驱动时保留 SPDX、版权和来源提交；更改另以项目补丁记录。
- 厂商 SDK、二进制编码库、面板初始化资料、芯片手册和硬件导出可能有不同分发条件。取得文件不代表获准公开再分发。
- 大体积原始手册、EDA 包和 SDK 保存在本地，被主仓库忽略；版本化来源/哈希记录仍进入主仓库。
- 后续发布前记录 Buildroot legal-info、组件清单、对应源码与补丁，不以本次初始化宣称已完成许可审查。
